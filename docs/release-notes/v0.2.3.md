# Eye眼 0.2.3

这一版只做一件小事，但每天都用得上：休息提醒把屏幕压成什么颜色，现在可以自己选。

以前只有一种——在你当前的色温上再压暖一档。想要更红的、更暗的，或者干脆换成
不偏暖的灰，都做不到。0.2.3 给了三档固定色温和一个取色器。

## 这一版变了什么

- **休息颜色可选**：20-20-20 到点时把屏幕短暂压成的那个颜色，现在有四档可选：
  - **跟随当前**（默认）：还是老行为，在当前色温上压暖一档；滤色模式下退回 1800K
  - **琥珀 1900K**：明显的暖黄，文字仍然清楚
  - **暖橙 2400K**：比琥珀更亮一点，适合白天
  - **深红 1200K**：最沉的一档，晚上快到睡前用
  - **自选**：点右边的色块，任意挑一个颜色，按原色落到屏幕上
- 三种选法亮度都会跟着压暗，几秒后恢复；压暗时长仍然和休息时长解耦。
- 老配置不用改：没有这一项的配置读出来就是「跟随当前」，升级前后的观感一样。
- 关掉「休息时调暗」时，整段颜色选择一起变灰，不会被误点。

## 有什么

一天里不再只有「白天一档、夜间一档」。完整功能：

- **24 小时曲线**：一天里放多个锚点，每个锚点定一个色温。锚点之间保持不变，
  离下一个锚点还剩设定的分钟数时才开始过渡——不会一整天都在缓慢变色，
  也不会到点「啪」一下突变。
- **锚点增删**：曲线上的锚点可以任意加减，最多 12 个，最少留 1 个。
  拖动只改预览，松手才写进配置。
- **自定义预设**：把当前色温（或滤色）和亮度一起存下来，起个名字，以后一点就用。
  内置的七个还在，自定义的排在后面，鼠标移上去可以删。
- **日出日落**：填经纬度，按当地的太阳时间决定什么时候变暖。冬至和夏至不用手动改。
  计算在本地做，不联网、不申请定位权限，极昼极夜会退回固定时刻。
- **工作日 / 周末**：两条独立曲线。周末默认跟着工作日，改一次就单独出去，
  也可以一键恢复跟随。
- **逐屏独立**：每块屏可以跟随全局、用自己的色温、或者用自己的滤色；
  亮度也能单独设。不用为此改全局设置再切回来。
- **20-20-20 落到屏幕上**：到点时屏幕会在休息里变色压暗，默认 6 秒后恢复
  （2–60 秒可配），不打开面板也能察觉；颜色可选「跟随当前 / 琥珀 / 暖橙 / 深红 /
  自取一色」。不想被这样提醒可以关掉，只留横幅。
- **在场感知**：超过两分钟没碰键鼠就暂停提醒和用眼计时，回来接着算。
  休息期间如果人还在用电脑，那一次不算「真正休息」。
- **全屏让位 / 演示模式**：前台是全屏内容时暂停写屏与提醒；也可以一键暂停 60 分钟，
  适合投屏和开会，到点自动恢复。
- **抢桌检测**：写屏前读回 Gamma 表，和上次自己写的比对。发现被别的软件改过
  （f.lux、Night Shift、显卡驱动）就暂停写屏并在面板上说明，不互相覆盖。
- **用眼记录**：今天亮了多久、休息了几次、当前连续看了多久、这一天最长连续多久，
  保留最近 30 天，并按钟点累计。电脑睡眠的那段不会算进去。
- **用眼建议**（默认关）：分析本地记录里最容易连续用眼的时段，给一句结论和
  一个「应用」按钮。点应用只往曲线里加锚点，不会替你打开「按时间自动」。
- **转暖倒数**：面板显示距离下一次转暖还有多久，日出日落模式下跟着当天日落走。
- **内置使用说明**：首页右上角打开 11 章说明，覆盖调色、预设、曲线、逐屏、
  20-20-20、用眼建议、隐私与常见问题。整篇内联在页面里，离线可读，不请求外部资源。
- **写屏不再空转**：目标色温和亮度没变就不重写 Gamma 表，用户操作和休息压暗不受影响。
  日志超过 2 MB 自动轮转，只留最近一份。

老配置不用手动迁移：读到只有 `dayKelvin` / `nightKelvin` 的配置时，
会自动补成两个锚点，原来的设置原样保留；没有 `restTint` 的配置按「跟随当前」处理。

## 安装

这个包**未签名**，装之前要先在插件中心打开「允许安装未签名开发包」。

1. 下载对应平台的 `com.eyecare.dbx-0.2.3-<target>.dbxp`
2. 插件中心 → 从本地安装，选这个文件
3. 装好后工作台会出现「Eye眼」标签页

`<target>` 是 `windows-x64` / `darwin-x64` / `darwin-arm64` / `linux-x64` / `linux-arm64`。

## 已知限制

- 休息色只影响压暗那几秒，不影响平时的色温曲线。
- 自选颜色是直接在 Gamma 表上缩放三个通道，选偏蓝的颜色同样会变暗，但不会有
  「暖」的观感——想要护眼效果，暖色档位更合适。
- 日出日落要自己填经纬度。插件没有定位权限，也不联网。
- 用眼记录只在插件跑着、并且护眼开关打开时累加。
- 用眼建议至少要攒够 3 天带钟点分布的新记录才给结论。
- **macOS 和 Linux 仍然只过了编译**，没有在真机上跑过。
- Wayland 会话里 GNOME 和 KDE 都不允许第三方改 Gamma 表，插件会直接把原因写在面板上。
- 亮度是软件层缩放，不是调显示器背光。
- 独占全屏的程序不受影响，这是 Gamma 表被绕过的正常现象。
- HDR 开启时 Gamma 表会被系统绕过，只有 Windows 能查到 HDR 状态。
